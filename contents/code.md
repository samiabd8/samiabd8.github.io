- <strong>KASN</strong> (Python and R), [GitHub](https://github.com/samiabd8/KASN), [PyPI](https://pypi.org/project/kasn/): packages for the deep sieve neural network framework introduced in my job market paper. Note that this differs from the replication repository [SieveKAN](https://github.com/samiabd8/SieveKAN) and the R code uses the PyPI package through reticulate. [![DOI](https://zenodo.org/badge/1441487237.svg)](https://doi.org/10.5281/zenodo.23852819) <!-- CHANGE WITH PACKAGE VERSION-->

- <strong>KASN_OptionPricing</strong> (Python), [GitHub](https://github.com/samiabd8/KASN_OptionPricing): replication scripts for the option pricing extension of the KASN framework.

- <strong>IVQRNN</strong> (Python), [GitHub](https://github.com/samiabd8/IVQRNN): features the experimental SGD (with momentum) alternative to grid search in this setting.

- <strong>KASN_DDCM</strong> (Python), [GitHub](https://github.com/samiabd8/KASN_DDCM): implementation of Example 3 in my job market paper, extending Norets (2012) to inference via neural networks in dynamic discrete choice models. 

- <strong>CH2003_LTE</strong> (Python), [GitHub](https://github.com/samiabd8/CH2003_LTE): PyTorch implementation of the Laplace-type estimator from Chernozhukov and Hong (2003). It accelerates quasi-Bayesian estimation using a vectorized ensemble of parallel MCMC chains with automatic CUDA GPU acceleration and CPU fallback.

- <strong>GrangerCausalityMatrix</strong> (Python, R), [GitHub](https://github.com/samiabd8/GrangerCausalityMatrix/): an implementation of GCMs introduced in my Master's thesis, completed with Damoon Shah. This calculates and visualizes directional causal relationships across multiple time series using a labeled matrix (similar to correlation tables) and a p-value heatmap.

- <strong>TemporalJEPA</strong> (Python), [GitHub](https://github.com/samiabd8/TemporalJEPA): experimental work on encoders designed for time-series forecasting across regimes with Damoon Shah.
