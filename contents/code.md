- KASN (Python and R), [GitHub](https://github.com/samiabd8/sieveKAN); code for the deep neural network framework introduced in my job market paper. <!-- CHANGE WITH PACKAGE VERSION-->

- KASN_OptionPricing (Python), [GitHub](https://github.com/samiabd8/KASN_OptionPricing); replication scripts for the option pricing extension of the KASN framework.

- IVQRNN (Python), [GitHub](https://github.com/samiabd8/IVQRNN); features the experimental SGD (with momentum) alternative to grid search in this setting.

- KASN_DDCM (Python), [GitHub](https://github.com/samiabd8/KASN_DDCM); implementation of Example 3 in my job market paper, extending Norets (2012) to inference via neural networks in dynamic discrete choice models. 

- CH2003_LTE (Python), [GitHub](https://github.com/samiabd8/CH2003_LTE); PyTorch implementation of the Laplace-type estimator from Chernozhukov and Hong (2003). It accelerates quasi-Bayesian estimation using a vectorized ensemble of parallel MCMC chains with automatic CUDA GPU acceleration and CPU fallback.

- GrangerCausalityMatrix (Python, R), [GitHub](https://github.com/samiabd8/GrangerCausalityMatrix/); an implementation of GCMs introduced in my Master's thesis, completed with Damoon Shah. This calculates and visualizes directional causal relationships across multiple time series using a labeled matrix (similar to correlation tables) and a p-value heatmap.

- TemporalJEPA (Python), [GitHub](https://github.com/samiabd8/TemporalJEPA); experimental work on encoders for time-series forecasting across regimes with Damoon Shah.
